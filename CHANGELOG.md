# Changelog

## 0.1.0 — 2026-10-09

- Initial browser and Windows desktop release.
- Searchable tool library with category filters and online/offline labels.
- Document, QR, text, developer and image utilities.
- JSON comparison ignores object key order and limits large comparisons.
- Regex testing runs in an isolated worker with a timeout and result cap.
- MIT license, source setup instructions and issue templates.

The Windows installer is unsigned. Updates are downloaded manually from GitHub Releases.
